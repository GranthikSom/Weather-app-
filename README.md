✨ Features

	•	📍 Get current location weather
	•	🌡️ Real-time temperature updates
	•	☁️ Dynamic weather conditions
	•	🎨 Beautiful Lottie weather animations
	

  🛠️ Built With
  
	•	💙 Flutter
